I'm learning to make games with Godot by making clones of the classics. I'm actually following this reddit thread [List of 49 simple games easy to clone for the beginner develop](https://www.reddit.com/r/gamedev/comments/sob61/list_of_49_simple_games_easy_to_clone_for_the/), or more acurately the first comment which lists them in order of difficulty (easy to difficult).

I'm under no delusion that I'm barely scratching the surface of game development. I'm beginning to understand the basics like movement (via physic vs via user control), collisions (layers and masks), managing state (score, interactions), signals (Event Driven development) etc.

It's mostly "copy a tutorial" at this stage, but the game that's come together the most so far is my snake clone:

<div align="center">![my snake clone in godot](/static/images/2026/snake_clone_godot_looping.gif)</div>

It's heavily based on this [Bacon and Games tutorial](https://www.youtube.com/watch?v=c7HQwxs5y8w), but I've refactored the code a little so the "snake" is a first class citizen and responsible for managing the snake. 

Thanks to https://opengameart.org/content/snake-game-assets for the assets.

Onwards and upwards.
